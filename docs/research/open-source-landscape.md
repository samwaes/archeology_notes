# Open-source landscape notes

This document records the direction established during the initial product research.

Candidate ecosystems previously identified for later evaluation include heritage knowledge platforms, 3D web viewers and point-cloud tooling rather than one monolithic application.

The current product direction is to combine a deliberately small application with open formats and specialist libraries instead of rebuilding photogrammetry, point-cloud registration or institutional heritage-management functionality.

Before adopting any specific external component in a production phase, re-check its current maintenance state, licence and format support at that time.
