# Future: heritage intelligence

This is explicitly outside the first MVP.

Potential later capability:

```text
photos + notes + voice transcripts + documents + GIS + 3D + point clouds
                              ↓
                 evidence-linked retrieval
                              ↓
                 suggested entities/relations
                              ↓
                     human confirmation
```

Useful future questions may include:

- Show everything recorded about this wall.
- Which observations concern moisture?
- What changed between the 2019 and 2026 survey?
- Which reports refer to this exact spatial area?
- Are there conflicting interpretations of the same feature?

Requirements before implementation:

- source citations/provenance
- clear separation of human observation and machine inference
- no silent rewriting of source records
- reproducible prompt/model/version metadata for generated analyses
- access controls inherited from the underlying evidence
