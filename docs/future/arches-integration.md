# Future: Arches and heritage interoperability

The MVP does not use Arches as its backend.

The architecture should nevertheless avoid choices that block later exchange with institutional heritage systems.

Relevant standards and directions to keep under review:

- CIDOC CRM
- CRMarchaeo
- CRMsci
- Arches / Arches for Science
- W3C Web Annotation
- IIIF
- RO-Crate
- GeoJSON
- E57
- COPC
- glTF
- 3D Tiles

The product should first validate the practical workflow, then map proven concepts into the appropriate standards rather than designing a complete ontology before users have validated the interaction model.
