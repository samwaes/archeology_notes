# Archeology Notes

Standalone Hupla Labs prototype for archaeologists and conservation professionals.

The product connects archaeological sites, physical objects, 3D survey representations, field observations, photographs, documents and conservation history while preserving authorship, provenance and original source assets.

Production target: https://archeology-notes.hupla.eu

See `docs/development-plan.md` and `docs/current-state.md` once Phase 0 is merged.
